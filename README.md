# 🚀 Curso de Python Fullstack

Este repositorio contiene todo el material, tareas y ejemplos de código para el **Curso de Python Fullstack IPIA 2025**. Está diseñado para ser un recurso centralizado para el aprendizaje y el seguimiento del progreso.

---

## 📂 Estructura del Repositorio

A continuación se detalla la organización del material en este repositorio.

### **📝 Tareas Pendientes**

* Aquí encontrarás todos los ejercicios y proyectos por completar. Cada tarea está etiquetada para su fácil identificación.

### **✅ Tareas Entregadas**

* Este directorio almacena los proyectos y ejercicios finalizados con sus respectivas soluciones. Es una excelente referencia para revisar trabajos anteriores.

### **💡 Ejemplos de Código**

* Este directorio contiene los archivos de ejemplo utilizados durante las clases para ilustrar conceptos y funcionalidades del curso.

### **🌐 Archivos Web**

* En esta sección se guardan todos los archivos relacionados con el desarrollo web, incluyendo:
    * **HTML:** Estructura de las páginas web.
    * **CSS:** Estilos y diseño visual.
    * **JavaScript:** Interactividad y lógica del lado del cliente.
    * **Bootstrap:** Ejemplos y componentes para el uso de este framework CSS.

### **📂 Otros Directorios**

* **`SQL`**: Material y ejemplos relacionados con bases de datos.
* **`React`**: Proyectos y ejemplos de la librería React.js.
* **`Tablón (Workspace)`**: Espacio de trabajo general para la clase.

---

## 🎓 ¿Cómo Usar este Repositorio?

1.  **Explora los directorios** para encontrar las tareas, ejemplos o material que necesites.
2.  **Consulta la carpeta `Tareas Pendientes`** para saber qué trabajos tienes que realizar.
3.  **Revisa la carpeta `Tareas Entregadas`** para comparar tus soluciones o entender mejor los ejercicios completados.
4.  Si tienes preguntas o necesitas clarificaciones, puedes referirte a los **ejemplos de código** o al material de las clases.
